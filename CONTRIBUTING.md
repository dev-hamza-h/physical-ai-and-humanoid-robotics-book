# Contributing to the Physical AI Humanoid Robotics Book

We welcome contributions from the community! This document outlines the workflow for contributing to the book.

## Research and Writing Workflow

We follow a "Digital Garden" or "iterative refinement" workflow. This approach allows for parallel work and avoids blocking writers on upfront research. It acknowledges that writing is a form of thinking and that ideas are refined over time. The workflow is as follows:

1.  **Research (Seeding)**: Initial, rough notes, links, and ideas are created.
2.  **Foundation (Outlining)**: The rough notes are structured into coherent outlines for chapters and sections.
3.  **Analysis (Drafting)**: Full prose is drafted based on the outlines, connecting ideas and forming arguments.
4.  **Synthesis (Publishing)**: The draft is reviewed, edited, and polished into a final, publishable chapter.

## Concurrent Work Process

To facilitate parallel contributions, we use a Git branching model based on features.

1.  **Create a Feature Branch**: Before starting work on a new chapter, a new feature, or a fix, create a new branch from `master`. The branch name should be descriptive of the work you are doing (e.g., `005-new-chapter-on-kinematics`).

2.  **Commit Your Changes**: Make your changes on the feature branch. Commit your changes with clear and descriptive commit messages.

3.  **Open a Pull Request**: When your work is ready for review, open a pull request against the `master` branch.

4.  **Review and Merge**: Your pull request will be reviewed by the maintainers. Once it is approved, it will be merged into the `master` branch.
